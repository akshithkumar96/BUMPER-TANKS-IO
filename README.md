# Bumper Tanks IO

A top-down, cross-platform arena brawler for WebGL and mobile. The project uses Unity 6, URP, C#, and Photon Fusion Shared Mode (introduced in the multiplayer module).

See [the implementation plan](docs/implementation-plan.md) for milestones, acceptance criteria, and commit boundaries.

## Foundation module

The current foundation supplies deterministic, testable arena bounds and tank motion primitives. Open the project with Unity `6000.3.8f1` and run Edit Mode tests from **Window > General > Test Runner**.
