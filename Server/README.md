# Bumper Tanks Game Service

Run locally with `dotnet run --project Server/BumperTanks.Server.csproj`.

Endpoints: `GET /health`, `GET /v1/profiles/{playerId}`, `POST /v1/rewards/daily`, `POST /v1/matches/complete`, and `GET /v1/leaderboard`.

Profile and reward data are persisted locally in JSON for development. The once-daily spin chooses 25, 50, 75, or 100 coins on the server and returns the award with the updated profile. Telemetry is retained across restarts and capped at the newest 10,000 events. Request validation accepts the 32-character hexadecimal player and match IDs generated by the Unity client, restricts telemetry to the game event names, and bounds submitted match totals.

Match completion uses HMAC-SHA256 attestation in non-Development environments by default. Configure `Rewards__MatchAttestationSecret` with at least 32 UTF-8 bytes and have the trusted multiplayer authority sign the newline-separated UTF-8 fields `playerId`, `matchId`, `gems`, and `eliminations`; send the lowercase hexadecimal signature in `X-Match-Attestation`. The signature must be generated by trusted server-side code. Never put the secret in the Unity client. `Rewards__RequireMatchAttestation` can explicitly enable or disable this check; unsigned match results are accepted by default only in Development. If production attestation is enabled without a valid secret, match completion returns `503`; absent and invalid signatures return `401` and `403` respectively.

Attestation proves that a trusted signer authorized the submitted values; it does not authenticate player identity or itself establish that the match authority computed those values honestly. Production deployment still needs authenticated player identity, a trusted multiplayer authority integration, and durable transactional storage. The current JSON repository is intended for development and single-instance use.

Profile data is persisted locally in `data/profiles.json`; override this with `Storage__ProfilePath` for a mounted volume.

## Container deployment

Build with `docker build -t bumper-tanks-service Server`. Run with `docker run -p 8080:8080 -e Cors__AllowedOrigins=https://your-game.example bumper-tanks-service`.
